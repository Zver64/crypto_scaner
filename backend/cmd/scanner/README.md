# scanner CLI

Утилита для создания, редактирования стратегий и бэктеста сохранённых стратегий через API работающего backend.

## Установка и обновление

Нужен Go 1.26+. Из корня репозитория выполните:

```sh
make install-cli
```

Установка использует обычный `go install`, без переопределения настроек Go. Для обновления после получения новых исходников выполните эту же команду.

Автодополнение рассчитано на zsh. Если каталог ниже ещё не подключён, добавьте эту строку в `~/.zshrc` **перед вызовом `compinit`**. Если используете Oh My Zsh, разместите её перед его загрузкой:

```zsh
fpath=(~/.local/share/zsh/site-functions $fpath)
```

Если используете обычный zsh без Oh My Zsh и ещё не настроили `compinit`, добавьте после этой строки:

```zsh
autoload -Uz compinit
compinit
```

Откройте новый терминал. Проверьте команду `scanner help` и автодополнение: наберите `scanner ` и нажмите Tab.

## Подключение

Создайте API-токен в Mini App → Settings → Tokens. Выполните команду и вставьте токен по запросу:

```sh
scanner login dev --server http://localhost:8080
```

`dev` — имя сохраняемого профиля. Для другого backend замените URL на его HTTPS-адрес.

Токен даёт права своего владельца, кроме управления API-токенами и загрузки истории свечей: это делается только в Mini App.

## Бэктест

Бэктест симулирует сделки сохранённой стратегии на одной монете по истории, хранящейся на сервере:

```sh
scanner backtest --strategy 3 --symbol BTCUSDT
scanner backtest --strategy 3 --symbol BTCUSDT --hold 48
```

Сделка открывается по цене открытия свечи после сигнала и закрывается по закрытию `hold`-й свечи; комиссия 0,1% на входе и на выходе. Одновременно открыта одна позиция: сигналы во время неё пропускаются (`skipped alerts`). Сделки, которым не хватило последовательных свечей (конец истории или пропуск), не учитываются (`unfinished trades`). По умолчанию `hold`: `1h` — 24, `1d` — 7, `1w` — 4, `1M` — 3; `--hold` принимает от 1 до 1000.

Вывод повторяет экран Backtest в Mini App: сначала таблица параметров (монета, период и интервал, `hold`, комиссия, пропущенные сигналы, незавершённые сделки), затем метрики стратегии со сравнением (`Net profit` — с `Buy & Hold`, покупкой в начале периода и продажей в конце; `Trades`, `Win rate`, `Profit factor` — с `Every candle`, входом на каждой свече с тем же `hold` и комиссиями), средние доходности против `Every candle` и до 50 последних сделок, от новых к старым. Без закрытых сделок после параметров печатается только причина `No trades: …`. Полный ответ, включая все сделки и кривую капитала, печатает `--json`.

## Редактирование сохранённой стратегии

```sh
scanner strategies update 6 --expr 'of("BTCUSDT", h_roc_12) < 0 && h_roc_12 > 0 && crosses_above(h_close, prev(h_max_12_high, 1)) && w_rsi < 50'
scanner strategies update 6 --name 'Test Weekly'
scanner strategies update 6 --message ''
```

Укажите положительный int64 ID и хотя бы один флаг: `--expr`, `--name`, `--message`.
Неуказанные поля сохраняются; пустой `--message` возвращает автоматически
генерируемый текст. Изменять можно только отключённую стратегию: для включённой
команда ничего не отправляет и сообщает `strategy N is enabled; edit it in the Mini App`.
Новая формула проверяется перед записью; недостающие индикаторы добавляются
автоматически, как при создании. `--json` печатает ответ API с обновлённой стратегией.
Команда читает текущие поля перед обновлением: не редактируйте ту же стратегию
одновременно в Mini App, чтобы не перезаписать параллельные изменения.

## Удаление сохранённой стратегии

Посмотрите ID через `scanner strategies`, затем удалите нужную стратегию:

```sh
scanner strategies delete 3
```

ID должен быть положительным int64. Команда удаляет стратегию без подтверждения.
При ответе API `204 No Content` обычный режим печатает `deleted strategy 3`,
а `scanner strategies delete 3 --json` ничего не выводит: JSON-тела нет.
Ошибки выводятся в stderr с ненулевым кодом завершения.

## Очистка неиспользуемых индикаторов

```sh
scanner indicators prune
```

Команда без подтверждения удаляет все настроенные индикаторы, которые **не читает
ни одна сохранённая стратегия, включая отключённые**, и которые **не показаны ни в
таблице рынка, ни на графике**. Индикатор, используемый хотя бы одним из этих
способов, остаётся. Это аналог действия **Remove unused** в Mini App.
Например, после удаления экспериментальных стратегий можно отдельно удалить
оставшиеся неиспользуемые индикаторы.

При ответе API `204 No Content` обычный режим печатает
`pruned scanner indicators used by no strategy, table or chart`.
С `--json` успешная очистка ничего не выводит: JSON-тела нет, число удалённых
индикаторов API не возвращает. Аргументы команда не принимает. Ошибки выводятся
в stderr с ненулевым кодом завершения.

После обновления исходников переустановите CLI через `make install-cli`, чтобы
новая команда и автодополнение появились в установленном `scanner`.

## Полное удаление

Из корня репозитория выполните:

```sh
make uninstall-cli
```

Команда удаляет установленный Go бинарник, файлы автодополнения и профили из `~/.config/scanner`. Для удаления используйте те же настройки Go, что при установке. Если запускали CLI с заданным `XDG_CONFIG_HOME`, удалите также каталог `$XDG_CONFIG_HOME/scanner`.

Удалите API-токен также в Mini App → Settings → Tokens: локальное удаление не отзывает его на сервере.

Уберите добавленную строку `fpath` из `~/.zshrc`, если этот каталог не нужен другим утилитам. Общий каталог автодополнений и `compinit` удалять не нужно. Откройте новый терминал.
