# Crypto Scanner

Сервис для поиска активных криптовалютных инструментов по характерному дневному диапазону цены на основе закрытых рыночных свечей.

## Language

**Сканирование рынка**:
Поиск всех активных инструментов, дневной диапазон которых соответствует заданным пользователем критериям. Основной пользовательский сценарий.
_Avoid_: Скрининг, поиск монет

**Анализ инструмента**:
Расчёт дневного диапазона для одного выбранного инструмента по заданному периоду и перцентилю. Второстепенный пользовательский сценарий.
_Avoid_: Проверка монеты, анализ символа

**Дневной диапазон**:
Относительная ширина закрытой дневной свечи, рассчитанная как разница максимальной и минимальной цены относительно цены открытия.
_Avoid_: Волатильность, изменение цены

**Дневная свеча**:
Закрытый суточный интервал рынка Binance Spot с календарными границами в UTC. Локальный часовой пояс пользователя не изменяет границы свечи.
_Avoid_: Локальный торговый день, сутки пользователя

**Период анализа**:
Количество последних закрытых дневных свечей, участвующих в расчёте.
_Avoid_: Таймфрейм, временной диапазон

**Перцентиль диапазона**:
Значение дневного диапазона, ниже которого находится заданная доля диапазонов за период анализа.
_Avoid_: Средний диапазон, вероятность движения

**Минимальный диапазон**:
Нижняя граница перцентиля диапазона, которую инструмент должен достичь, чтобы попасть в результат сканирования рынка.
_Avoid_: Минимальная волатильность

**Результат сканирования**:
Упорядоченный список инструментов, удовлетворяющих критериям сканирования рынка.
_Avoid_: Карточки монет, рекомендации
